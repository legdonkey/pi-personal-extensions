速查：命令、配置和常见问题

想做什么对应哪个菜单项；五个配置文件在哪；出问题时先查什么。

想找某项设置在哪

常用设置都从 /personal 进入：先选功能，再选二级菜单里的设置项。表里按「想做什么」列出菜单路径。

Pi 自带的 /reload、/name 照常直接输入。例外：你发的消息里的路径是否变成链接（userMessages）没有菜单项，要手改 clickable-paths.json。

想找配置文件

五个配置文件都在 agent 目录，默认是 ~/.pi/agent/。 设置环境变量 PI_CODING_AGENT_DIR 后，五个文件改用它指定的目录。 平时不用手改这些文件。用 /personal 菜单改全局设置，会自动保存到对应文件。

改了设置没生效，要不要 /reload

在别的会话改过设置、手改过配置文件，或刚装好、更新过扩展，已打开的会话要输入 /reload。 在当前会话用 /personal 菜单改，不用重载。

想更新扩展

在仓库根目录执行 git pull，再在 Pi 里输入 /reload。依赖有变化时，先重新安装依赖。 

# 在仓库根目录
git pull
# 依赖有变化时
npm install --ignore-scripts \
  --registry=https://registry.npmmirror.com
# 然后在 Pi 里输入 /reload

从旧版本升级后，设置会自动迁移：旧的「额度与会话 ID」「状态栏风格选择」两个开关合成一个，只有两者都关闭时才保持关闭；其他设置原样保留。

出问题怎么办

各功能出问题时先查什么，汇总在排查表里。

打开方式选 file 时，系统用默认程序打开文件，不跳到具体行。换打开方式后，让 Pi 重新输出一个文件路径，再点新消息里的链接测试；旧消息里的链接不会更新。
