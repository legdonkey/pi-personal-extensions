状态栏：看额度，换配色

「状态栏：额度、会话 ID 与配色」在状态栏显示剩余额度和会话 ID，也能给状态栏换配色。

功能
状态栏：额度、会话 ID 与配色（一个开关）
菜单路径
/personal → 状态栏：额度、会话 ID 与配色
前提
换配色需要先装 npm:@narumitw/pi-statusline；Antigravity 额度需要先装 pi-antigravity
配置文件
agent 目录下的 pi-statusline.json（默认 ~/.pi/agent/）

想看懂状态栏上的额度和会话 ID

「状态栏：额度、会话 ID 与配色」在状态栏显示两样东西：当前会话 ID 的末尾 8 位，和当前服务商还剩多少额度。 用 openai-codex 时显示周额度（weekly）；用 zai-coding-cn 时，前面多一段 5 小时额度（5h）。用 kimi-coding 时也显示 5 小时额度，老套餐附周额度，新套餐附月度额度（monthly）。用 antigravity 时显示 quota 60% left 这样的当前模型配额。这个配额可能使用共享池，不是独立的 5 小时或周额度，也不是 token 计数。

  • 额度、会话 ID 和配色是同一项功能，共用一个开关。升级时，旧版的两个开关合成这一个：只有两个旧开关都关闭，才保持关闭；否则开启。

额度一项是空的怎么办

  1. 先看当前模型的服务商。只有 openai-codex、zai-coding-cn、kimi-coding 和 antigravity 显示额度。用其他服务商时，额度一项为空，属正常。
  2. 如果服务商是这四个之一，额度却还是空的：确认已登录这个服务商，并确认网络能连通。Antigravity 还要确认已启用 pi-antigravity。
  3. 等下一次查询，大约每 5 分钟一次；切换模型时会立即发起查询。其他服务商的数字一直不变，可能是查询失败，显示的是上次的值。Antigravity 查询失败会隐藏旧值。
  • 更新时机：会话开始、在会话树里跳转、切换模型时立即发起查询；之后每 5 分钟查询一次；Pi 每回复完一轮也会查询，但距上次查询开始不足 30 秒就跳过（失败的查询也算）。
  • Antigravity 每次查询重新读取当前账号凭据。账号变化在下一刷新生效，扩展不主动监听账号切换。切换模型会强制查询，不显示旧模型缓存。

想换状态栏配色

这里修改的是 pi-statusline 的自定义配色，不改变 Pi 主题。需要先安装并启用 pi-statusline。

pi install npm:@narumitw/pi-statusline
  1. 输入 /personal，选「状态栏：额度、会话 ID 与配色」。
  2. 选「选择 pi-statusline 自定义配色」，打开配色列表。
  3. 用 ↑ ↓ 键选一套配色，列表下方的预览条实时换色。
  4. 按 Enter 键应用，按 Esc 键放弃。

应用后覆盖原来的自定义配色，并设为紧凑布局和圆角分隔符，Pi 自动重载。

  • Pi 正在回复或压缩上下文时，自动重载会被拒绝。等结束后再应用，或结束后手动输入 /reload。
  • 终端支持实时预览；RPC 客户端使用普通列表选择，不显示预览。
  • 设置写在 agent 目录的 pi-statusline.json，其他设置不变。如果写入失败，Pi 提示「应用失败」，不重载。
