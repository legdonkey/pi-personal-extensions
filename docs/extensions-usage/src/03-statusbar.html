状态栏：看额度，换配色

「额度与会话 ID」在状态栏显示剩余额度和会话 ID。「状态栏风格选择」给状态栏换配色。

功能
额度与会话 ID · 状态栏风格选择
菜单路径
/personal → 状态栏风格选择
前提
换配色需要先装 npm:@narumitw/pi-statusline
配置文件
agent 目录下的 pi-statusline.json（默认 ~/.pi/agent/）

想看懂状态栏上的额度和会话 ID

「额度与会话 ID」在状态栏显示两样东西：当前会话 ID 的末尾 8 位，和当前服务商还剩多少额度。 用 openai-codex 时显示周额度（weekly）；用 zai-coding-cn 时，前面多一段 5 小时额度（5h）。

额度一项是空的怎么办

  1. 先看当前模型的服务商。只有 openai-codex 和 zai-coding-cn 显示额度。用其他服务商时，额度一项为空，属正常。
  2. 如果服务商是这两个之一，额度却还是空的：确认已登录这个服务商，并确认网络能连通。
  3. 等下一次查询，大约每 5 分钟一次；切换模型时会立即发起查询。数字一直不变，可能是查询失败，显示的是上次的值。
  • 更新时机：会话开始、在会话树里跳转、切换模型时立即发起查询；之后每 5 分钟查询一次；Pi 每回复完一轮也会查询，但距上次查询开始不足 30 秒就跳过（失败的查询也算）。

想换状态栏配色

「状态栏风格选择」只负责换配色。状态栏本身来自 pi-statusline 包，需要先安装并启用。

pi install npm:@narumitw/pi-statusline
  1. 输入 /personal，选「状态栏风格选择」。
  2. 选「预览并选择配色」，打开配色列表。
  3. 用 ↑ ↓ 键选一套配色，列表下方的预览条实时换色。
  4. 按 Enter 键应用，按 Esc 键放弃。

应用后 Pi 自动重载。密度和分隔符也会一起换成 compact 和 round。

  • Pi 正在回复或压缩上下文时，自动重载会被拒绝。等结束后再应用，或结束后手动输入 /reload。
  • 想直接应用某一套：第 2 步改选「应用配色：编号. 名称」，例如「应用配色：11. Claude 暖纸」。这样不打开配色列表，选完立即应用。
  • 配色列表只能在 Pi 终端界面里打开；直接应用的菜单项在其他带界面的客户端里也能用。
  • 设置写在 agent 目录的 pi-statusline.json，其他设置不变。如果写入失败，Pi 提示「应用失败」，不重载。
