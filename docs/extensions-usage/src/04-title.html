会话名：自动起名，手动改名优先

会话名显示在哪，「自动会话命名」什么时候起名、起出来什么样，怎么暂停、预览、换命名模型，要注意什么。

功能
「状态栏会话标题」显示会话名；「自动会话命名」起会话名
入口
/personal → 自动会话命名：查看状态、选择命名模型、选择命名思考强度、预览建议标题、暂停当前会话命名、恢复当前会话命名
适用场景
在 Pi 终端界面里自动起名。用 pi -p 等非交互方式运行时，不起名。

会话名在哪里

会话名合入状态栏，不再单独占行，也不强制右对齐。还没有会话名时，这里显示「未命名会话」。

会话标题是状态栏独立功能开关中的第五项，配置为 sessionTitleEnabled。新字段优先；缺失时沿用旧 session-title 布尔值，旧显式关闭只关闭标题。新旧项都校验，读取不写文件；总开关关闭不删除独立设置。

自动起名：什么时候起、起成什么样

每轮正常结束后，「自动会话命名」在后台起名。你不用等，可以直接输入下一条消息。 会话名由一个类别图标、对象和目标组成。

  • 在两种情况下会话名不变：当前会话名已经准确；对话信息不够。

手动改了会话名，怎么恢复自动起名

用 /name 手动改会话名后，这个会话暂停自动起名。 想恢复，在 /personal → 自动会话命名 里选「恢复当前会话命名」，下一轮结束后生效；选「暂停当前会话命名」，可以主动暂停。

  • 如果打开的会话已经有会话名，而且不是自动起的，「自动会话命名」在这个会话里也是暂停状态。
  • 恢复后，「自动会话命名」会接着改当前的会话名。

想先看看会起什么名

在 /personal → 自动会话命名 里选「预览建议标题」，可以看到建议的会话名。它只弹出提示，不改会话名。

  • 等 Pi 回复完，再预览。暂停状态下也能预览。
  • 预览同样消耗命名模型的额度。

想换命名模型

在 /personal → 自动会话命名 里选「选择命名模型」，再从列表里选一个。列表只列出 /scoped-models 里已认证的模型。

  • 默认命名模型是 gpt-5.6-luna。命名模型只用来起名，对所有会话生效，不影响主对话。
  • 命名用的思考强度：在同一个二级菜单里选「选择命名思考强度」。默认跟随 Pi 对这个模型的设置；Pi 没设置时用 low。实际用的思考强度受命名模型支持的范围限制。命名模型不支持思考时，用 off。
  • 换成另一个命名模型后，命名用的思考强度恢复成默认值。

想看当前设置

在 /personal → 自动会话命名 里选「查看状态」，一条提示里能看到是否开启、命名模型和命名用的思考强度。

要注意什么：额度和隐私

每次自动起名和预览，都额外消耗命名模型的额度，不计入 Pi 自带的用量统计。 「自动会话命名」把当前会话名和最近最多 5 轮对话的文字发给命名模型，可能含业务信息；工具输出、思考内容和图片不发送。

会话名一直没变怎么办

  1. 在 /personal 里确认「自动会话命名」已加载，再进入它的菜单选「查看状态」。
  2. 如果显示暂停，选「恢复当前会话命名」。
  3. 如果提示命名模型不可用，先用 /login 完成服务商认证，再用 /scoped-models 选出明确的模型范围，按 Ctrl+S 保存。也可以在菜单里选「选择命名模型」，换一个命名模型。
  4. 如果以上都正常，选「预览建议标题」试一次。
  • 在 /scoped-models 里全选所有模型时，「自动会话命名」会认为没有可用的命名模型。按 Esc 键只关闭列表，不保存。
