总览：五项功能分别做什么

五项功能各改界面的哪一块。

入口文件
extensions/pi-personal-extensions.ts
管理命令
/personal
开关文件
personal-extensions.json，默认在 ~/.pi/agent/，可用 PI_CODING_AGENT_DIR 改目录

pi-personal-extensions 是一个 Pi 扩展合集，共五项功能。后文单说「扩展」，指正在讲的那项功能的代码。 入口是 Pi 加载的那个文件。入口按 personal-extensions.json 里的开关加载五项功能，还注册 /personal 命令，用来启停和设置。

  • 消息区有两项：用户消息橙色线框，和文件路径可点击。
  • 状态栏由一项功能负责：它把额度、会话 ID 和回复结束后的 token 速度写进扩展状态行，还给 pi-statusline 那一行换配色。
  • 状态栏中的会话名由合并后的 statusline 显示；自动会话命名在一轮正常结束后，用命名模型在后台起名。
  • 状态栏里的 🧠 段来自原位思考强度。它支持 GPT-6 Codex、Anthropic 协议分支的四个指定 Claude 模型和 Antigravity 分支的两个指定 Claude 模型，为新用户消息选择思考强度。

五项功能默认全部开启，每一项都能单独关闭。
