原位思考强度：每条消息自动选档位

用 GPT-6 Codex、Anthropic 协议分支的三个指定 Claude 模型或 Antigravity 分支的两个指定 Claude 模型时，按每条新消息的难度自动选档位，你不用手动切换。不用这些模型可以跳过本章。

功能
原位思考强度
入口
/personal → 原位思考强度（Jev / d1-ultra）
配置文件
agent 目录下的 inline-effort.json（默认 ~/.pi/agent/）；升级后原有设置自动保留

「原位思考强度」能帮你什么

思考强度分五个档位。「原位思考强度」给每条新消息在 low 到 max 之间自动选一档，你不用手动切换。 它只调档位，不换主模型。 扩展按本轮任务的推理复杂度选档：low 到 xhigh 对应直接操作、局部判断、多约束综合与耦合推理四档常规工作，max 是例外攻坚档。 近期对话只补全同一任务的信息，不继承旧难度。示例：修改位置和方式明确的字号调整可用 low，改做图示设计可用 high；按成熟口径查数画图可用 medium，排查混杂原因可用 xhigh。示例不是线上分类保证。 不因专业主题、成片精美、代理多或反复报错自动提档；只有无法识别任务要求时才以 high 保守兜底。思考强度不替代模型专长、授权和实测。分类器只读有限文本，看不到图片和工具结果，同轮工具续调不重新分类，历史决策不变。

想让它生效

需要用支持的模型、开启 thinking，并配好 OpenRouter 认证。使用 Codex 还要登录 openai-codex。使用 Antigravity 还要先安装并启用 pi-antigravity。主模型的接口和模型能力也有要求，完整条件写在本节的「适用条件」列表里。

  1. 用支持的模型启动 Pi，thinking 设为 medium。下面用 GPT-6 Codex 举例。
  2. 输入 /personal，选原位思考强度，再选「查看分类模型与状态」。看到「适用」，说明主模型和 thinking 符合条件。
  3. 在同一个菜单里选「测试分类模型可用性」，确认分类器能用。
  4. 发一条消息，看 🧠 段的档位。切换警告只表示首选失败，Jev 回退成功后会显示实际档位；全部失败才沿用当前档位。Codex 出现「未调整」，表示这次没有调整档位，按基线发出。

三个分支的写入方式不同。Codex 在当前用户消息前插入 configuration_update。Anthropic 协议分支只修改 Pi 已生成的末尾空 system 消息中的 output_config.effort，不改顶层配置、历史消息或 thinking block。 Antigravity 是独立分支。扩展临时包装插件原生 streamSimple，只改匹配主请求的 options.reasoning，由插件按 runtime ID 路由。max 和 xhigh 夹到 high，不改会话 thinking 或历史上下文。

状态栏的 🧠 段怎么读

🧠 段从左到右是：实际档位、基线和分类器。基线是 Pi 当前的 thinking 设置。 Pi 自带的 thinking 显示只是基线，实际档位看 🧠 段。

想看现在的状态

在 /personal 的原位思考强度菜单里选「查看分类模型与状态」，看是否适用、之后用哪个分类器、失败回退策略、上一条消息选到的档位。

想换分类器

  1. 输入 /personal，选原位思考强度。
  2. 选「选择分类模型」。
  3. 用 ↑ ↓ 键选 Jev 或 d1-ultra。
  4. 按 Enter 键保存；按 Esc 键放弃。两种操作都会返回二级菜单。

新分类器对所有会话生效。如果 Pi 正在回复，先等它回复完，再切换。

分类失败怎么办

d1-ultra 超时、出错或结果无效时，警告会说明原因并提示「正在切换到 Jev」。有效结果的概率低于 0.5 时也尝试 Jev，但不发警告。Jev 成功后，提示实际档位，状态栏显示「Jev（d1-ultra 回退）」。 最终没有合格结果时沿用当前档位，只报告实际错误；仅有低置信度时不发警告。可在 /personal 的原位思考强度菜单里选「测试分类模型可用性」检查。 自动回退只影响本次，不改全局选择，下一条新消息仍先尝试 d1-ultra。直接选择 Jev 时不反向回退。用户取消时停止分类，不回退，也不写决策。

要注意什么：额度和隐私

每个分类模型最多等 15 秒，含回退最多约 30 秒。分类和回退都消耗 OpenRouter 额度；d1-ultra 是付费模型。 「原位思考强度」把当前消息和之前最多 6 条对话消息的文本发给分类器，可能含业务信息。工具输出、思考内容和图片不发送。
